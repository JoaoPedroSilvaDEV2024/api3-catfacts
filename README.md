# 🐱 Cat Facts - Curiosidades sobre Gatos

Este é um projeto simples de uma página web que consome APIs públicas para exibir fatos aleatórios e imagens de gatos. Ideal para amantes de pets que buscam uma dose rápida de entretenimento!

## 🚀 Funcionalidades

- **Gerar Fato:** Ao clicar no botão, um novo fato sobre gatos é buscado e exibido na tela.
- **Imagem Dinâmica:** Uma nova imagem de gato é carregada a cada clique, garantindo que você sempre veja um gatinho diferente.
- **Totalmente Responsivo:** O layout se adapta perfeitamente a dispositivos móveis, tablets e monitores desktop.
- **Animações Suaves:** Efeitos de hover e transições que tornam a experiência de usuário mais agradável.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação da página.
- **CSS3:** Estilização avançada, gradientes, flexbox e media queries.
- **JavaScript (ES6+):** Lógica de consumo de APIs e manipulação assíncrona do DOM.
- **APIs:**
    - [Cat Fact API](https://catfact.ninja): Fonte dos fatos.
    - [CATAAS (Cat as a Service)](https://cataas.com): Fonte das imagens.

## 📂 Estrutura do Projeto

```text
├── index.html    # Estrutura principal
├── style.css     # Estilos e responsividade
└── script.js     # Lógica de consumo da API
```

## ⚙️ Como executar

Não é necessário configurar um servidor. Basta seguir os passos:

1. Baixe os arquivos do repositório.
2. Certifique-se de que os três arquivos estão no mesmo diretório.
3. Abra o arquivo `index.html` em seu navegador de preferência.
